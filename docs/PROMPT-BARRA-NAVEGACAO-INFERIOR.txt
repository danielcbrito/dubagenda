--------------------------------------------------------------
1. ESTRATÉGIA DE DESIGN (por que cada decisão existe)
--------------------------------------------------------------
Objetivo: sensação de APP NATIVO (estilo Instagram/Facebook),
nunca de "site responsivo" ou "template de admin".

- EXATAMENTE 4 abas. Nunca 5. Sem FAB central dentro da barra.
- Altura fixa 64px (h-16) + padding de safe-area (iOS/Android).
- Fundo: bg-background/95 + backdrop-blur-md (vidro sutil).
- Borda superior: border-t border-border/30 (nunca linha forte).
- Ícones OUTLINE (contorno), NUNCA preenchidos por padrão.
- Tamanho do ícone: 26x26px (h-[26px] w-[26px]). Não usar 20/24.
- Cor INATIVA: text-foreground (PRETO real). Decisão explícita:
  cinza (muted-foreground) deixava a barra apagada e sem vida.
- Cor ATIVA: text-primary. Sem pílula, sem underline, sem
  layoutId — a mudança é SÓ de cor e peso de traço, em 200ms.
- strokeWidth: 1.8 inativo / 2.2 ativo.
- DISTÂNCIA ÍCONE → TÍTULO: gap-2 (8px). Regra crítica.
  Foi ajustado de gap-1 (4px) para gap-2 porque o texto ficava
  colado no ícone. NÃO reduzir para gap-1 nem aumentar para gap-3.
- Label: text-[10px], leading-none, tracking-wide.
  Inativo: font-normal + text-foreground.
  Ativo:   font-medium + text-primary.
- Alinhamento vertical: justify-start + pt-2 pb-2. Isso trava a
  altura do conteúdo e evita "dança" vertical ao trocar de aba.
- Cada item: flex-1 (larguras exatamente iguais).
- Feedback tátil obrigatório: whileTap={{ scale: 0.94 }}.
- Badge numérico opcional: bolinha primary de 18px,
  ring-2 ring-background, "99+" no limite.
- z-index 60 — acima de conteúdo e de bolhas flutuantes.
- Tokens semânticos SEMPRE. PROIBIDO text-white / bg-black /
  bg-gray-* / hex hardcoded.

Regras de layout que acompanham a barra:
- Container raiz da rota recebe
  paddingBottom: calc(4rem + env(safe-area-inset-bottom, 0px))
  quando a barra está visível — conteúdo nunca fica por baixo.
- Fluxos imersivos (criação/checkout/pagamento) ESCONDEM a barra.
- Botão flutuante (suporte/FAB) sobe acima da barra:
  bottom: calc(4rem + env(safe-area-inset-bottom, 0px) + 0.875rem)

3. OS ÍCONES — REGRA MAIS IMPORTANTE DO DOCUMENTO
--------------------------------------------------------------
Os 4 ícones são SVGs autorais desenhados com a MESMA gramática
visual. NÃO substituir por ícones de biblioteca. NÃO redesenhar.
Copiar os paths exatamente como estão.

GRAMÁTICA VISUAL COMUM (todo ícone novo do app deve seguir):
  • viewBox="0 0 24 24", fill="none"
  • Traço único contínuo, sem preenchimento
  • stroke="currentColor" (a cor vem do className, nunca fixa)
  • strokeWidth padrão do path = 1.9 (o componente sobrescreve
    para 1.8 inativo / 2.2 ativo via prop)
  • strokeLinejoin="round" e strokeLinecap="round" SEMPRE
  • Geometria "cheia": a forma ocupa de ~3 a ~21 no viewBox,
    deixando margem óptica de 3px em volta
  • Cantos arredondados generosos (raio visual ~1.5–2.5)
  • ZERO detalhes internos supérfluos. Um ícone = 1 a 3 traços.
  • Silhueta reconhecível a 26px — teste sempre nesse tamanho.

/* ---- Item da barra ---- */

interface NavItemProps {
  icon: React.ElementType;
  label: string;
  isActive?: boolean;
  onClick: () => void;
  badge?: number;
}

function NavItem({ icon: Icon, label, isActive, onClick, badge }: NavItemProps) {
  return (
    <motion.button
      whileTap={{ scale: 0.94 }}
      onClick={onClick}
      className="relative flex flex-1 flex-col items-center justify-start gap-2 px-1 pt-2 pb-2"
    >
      <div className="relative">
        <Icon
          className={`h-[26px] w-[26px] transition-all duration-200 ${
            isActive ? "text-primary" : "text-foreground"
          }`}
          strokeWidth={isActive ? 2.2 : 1.8}
        />
        {typeof badge === "number" && badge > 0 && (
          <span className="absolute -top-1.5 -right-2 min-w-[18px] h-[18px] px-1 rounded-full bg-primary text-primary-foreground text-[10px] font-bold flex items-center justify-center tabular-nums leading-none ring-2 ring-background">
            {badge > 99 ? "99+" : badge}
          </span>
        )}
      </div>
      <span
        className={`text-[10px] leading-none tracking-wide transition-colors duration-200 ${
          isActive ? "font-medium text-primary" : "font-normal text-foreground"
        }`}
      >
        {label}
      </span>
    </motion.button>
  );
}

/** Barra de navegação inferior fixa com 4 abas. */
export function BottomNavigation() {
  const location = useLocation();
  const navigate = useNavigate();
  const isActive = (path: string) => location.pathname === path;

  return (
    <nav
      className="fixed bottom-0 left-0 right-0 z-[60] border-t border-border/30 bg-background/95 backdrop-blur-md"
      style={{ paddingBottom: "env(safe-area-inset-bottom, 0px)" }}
    >
      <div className="mx-auto flex h-16 w-full items-stretch justify-around">
        <NavItem icon={HomeIcon}     label="Início"  isActive={isActive("/")}        onClick={() => navigate("/")} />
        <NavItem icon={CalendarIcon} label="Agenda"  isActive={isActive("/agenda")}  onClick={() => navigate("/agenda")} />
        <NavItem icon={SendIcon}     label="Disparo" isActive={isActive("/disparo")} onClick={() => navigate("/disparo")} />
        <NavItem icon={ProfileIcon}  label="Perfil"  isActive={isActive("/perfil")}  onClick={() => navigate("/perfil")} />
      </div>
    </nav>
  );
}

IMPORTANTE: o componente do ícone RECEBE strokeWidth como prop.
Por isso os paths precisam manter stroke="currentColor" mas o
strokeWidth do path é sobrescrito pelo atributo do <svg> apenas
se você mover strokeWidth para o <svg>. Neste projeto o valor
1.9 do path é o fallback e o efeito de peso ativo/inativo vem
do prop no <svg> — mantenha os dois exatamente como no código.

5. CÓDIGO — layout raiz (src/routes/RootLayout.tsx)
--------------------------------------------------------------
import { Outlet, useLocation } from "react-router-dom";
import { BottomNavigation } from "@/components/BottomNavigation";

/** Layout mobile-first com barra inferior fixa. */
export function RootLayout() {
  const { pathname } = useLocation();

  // Fluxos imersivos escondem a barra (ajuste às rotas do projeto)
  const hideNavPatterns = ["/disparo/novo", "/agenda/novo", "/checkout"];
  const shouldShowNav = !hideNavPatterns.some((p) => pathname.startsWith(p));

  return (
    <div
      className="relative min-h-dvh w-full touch-pan-y overflow-x-hidden bg-background antialiased"
      style={
        shouldShowNav
          ? { paddingBottom: "calc(4rem + env(safe-area-inset-bottom, 0px))" }
          : undefined
      }
    >
      <Outlet />
      {shouldShowNav && <BottomNavigation />}
    </div>
  );
}
